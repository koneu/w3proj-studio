# Region Editor

Extension `w3.terrainRegions`. Region Editor of the terrain editor: draw, move, resize, name, weather, ambient sound, colour.

## Data
Reads and writes map/war3map.w3r.json; reads map/war3map.w3i.json. MCP tools add and list regions.

## Contributes
- MCP tools (4): add_region, remove_region, set_weather, list_regions
- Needs: w3.terrainViewer

Full list: `extension.json` in this folder.
