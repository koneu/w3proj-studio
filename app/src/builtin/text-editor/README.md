# Text Editor

Extension `w3.textEditor`. CodeMirror editor with JASS, Lua and JSON highlighting; offers code editors to other extensions (service w3.codeEditor).

## Data
Reads and writes the opened text file in the project; no map data of its own.

## Contributes
- Commands (2): w3.text.revealAt, w3.text.revealLine
- Editors (1): w3.textEditor
- Services (1): w3.codeEditor

Full list: `extension.json` in this folder.
