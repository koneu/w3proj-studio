# Model Viewer

Extension `w3.modelViewer`. 3D view of MDX (v800-v1800) and MDL models: animations, team colour, textures from the map or the game.

## Data
Reads the opened model and its textures from the project or the game; writes nothing.

- Editors (2): w3.modelViewer, w3.modelViewer
