# Gameplay Constants & Game Interface

Extension `w3.gameSettings`. Editors for Gameplay Constants and Game Interface (the game's default values shown beside the map's changes), for a map or a campaign.

## Data
Map: map/war3mapMisc.txt, map/war3mapSkin.txt, texts in map/war3map.wts, map/war3map.w3i.json. Campaign: map/war3campaignMisc.txt, map/war3campaignSkin.txt, map/war3campaign.wts, map/war3campaign.w3f.json. Only changed values are stored.

## Contributes
- Commands (2): w3.gameplayConstants.open, w3.gameInterface.open
- Editors (1): w3.gameSettings

Full list: `extension.json` in this folder.
