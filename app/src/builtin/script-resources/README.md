# Script Resources

Extension `w3.scriptResources`. Completion in map scripts and custom text: file paths, sound labels, order strings, and rawcodes with the game's and the map's objects.

## Data
Reads the game's files, the map's imports and objects; writes nothing. Contributes no commands or views of its own.

## Contributes
- Needs: w3.textEditor

Full list: `extension.json` in this folder.
