# Object Manager

Extension `w3.objectManager`. Everything the map contains and uses (placed objects, custom objects, regions, cameras, sounds, triggers, variables, imports) with the triggers using each.

## Data
Reads the map's files (war3map.w3s/w3r/w3c/w3i, war3mapUnits.doo, war3map.doo, war3map.imp, the script and strings); writes nothing.

## Contributes
- Commands (3): w3.objectManager.refresh, w3.objectManager.summary, w3.objectManager.reveal
- Views (1): w3.objectManager.tree
- Needs: w3.objectEditor

Full list: `extension.json` in this folder.
