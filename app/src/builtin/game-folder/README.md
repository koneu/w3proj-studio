# Game Folder

Extension `w3.gameFolder`. Finds the installed Warcraft III when the configured folder does not open and lets the user choose one.

## Data
Reads folder locations on disk; writes the chosen game folder setting. No map data.

## Contributes
- Commands (1): w3.game.chooseFolder
- Settings (1): game.askForFolder

Full list: `extension.json` in this folder.
