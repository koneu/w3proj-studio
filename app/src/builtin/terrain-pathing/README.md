# Pathing Editor

Extension `w3.terrainPathing`. Shows the pathing map over the terrain and paints manual overrides (walk, fly, build).

## Data
Writes overrides to .w3proj/pathing.json in the project; they are applied whenever map/war3map.wpm is generated.

## Contributes
- Needs: w3.terrainViewer

Full list: `extension.json` in this folder.
