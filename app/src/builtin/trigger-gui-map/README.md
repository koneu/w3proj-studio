# Trigger Map Objects

Extension `w3.triggerGuiMap`. A Map tab in the GUI trigger parameter dialog: regions, cameras, sounds, music, triggers and placed objects as their generated globals (gg_rct_..., gg_unit_...).

## Data
Reads map/war3map.w3r, w3c, w3s (as .json) and the placed units/doodads (map/war3mapUnits.doo, map/war3map.doo); writes nothing.

## Contributes
- Needs: w3.triggerGui, w3.objectEditor, w3.terrainViewer

Full list: `extension.json` in this folder.
