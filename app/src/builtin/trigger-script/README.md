# Custom Script Triggers

Extension `w3.triggerScript`. Triggers converted to custom text: their JASS or Lua code, editable.

## Data
Reads and writes the trigger's script text in the trigger editor's document (map/triggers/... and war3map.wct); the generated map/war3map.j is read for display.

## Contributes
- Needs: w3.triggerEditor

Full list: `extension.json` in this folder.
