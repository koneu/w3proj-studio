# Settings Editor

Extension `w3.settingsEditor`. Edits the declared settings of the workbench and all extensions, for the user or the open project.

## Data
Reads the declared settings of all extensions; writes settings.json (user settings folder or the project).

## Contributes
- Commands (1): w3.settings.open
- Editors (1): w3.settingsEditor

Full list: `extension.json` in this folder.
