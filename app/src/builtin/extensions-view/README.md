# Extensions View

Extension `w3.extensionsView`. Lists the installed extensions and where user extensions live.

## Data
Reads the extension manifests (extension.json) the host loaded; the sample command writes a sample extension into the user extensions folder.

## Contributes
- Commands (2): w3.extensions.openFolder, w3.extensions.createSample
- Views (1): w3.extensions.installed

Full list: `extension.json` in this folder.
