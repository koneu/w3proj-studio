# GUI Triggers

Extension `w3.triggerGui`. Shows events, conditions and actions of GUI triggers as the game words them, with category icons and nested blocks (service w3.triggers.gui).

## Data
Edits the GUI trigger data of the trigger editor's documents (map/triggers/*.gui.json); can create variables for pasted lines (setting triggers.autoCreateVariables).

## Contributes
- Services (1): w3.triggers.gui
- Settings (1): triggers.autoCreateVariables
- Needs: w3.triggerEditor

Full list: `extension.json` in this folder.
