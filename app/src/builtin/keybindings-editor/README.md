# Keyboard Shortcuts

Extension `w3.keybindingsEditor`. Every command with its keys: search, record, remove, reset to default, conflicts shown.

## Data
Reads and writes keybindings.json in the settings folder (not in the project).

- Editors (1): w3.keybindingsEditor
