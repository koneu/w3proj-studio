# Trigger Object Pickers

Extension `w3.triggerGuiObjects`. Parameter editors for GUI triggers: unit, item, ability, buff, destructable, doodad and upgrade types chosen in the object browser.

## Data
Reads the game's and the map's object data through the object editor's service (w3.objects); writes nothing itself.

## Contributes
- Needs: w3.triggerGui, w3.objectEditor

Full list: `extension.json` in this folder.
