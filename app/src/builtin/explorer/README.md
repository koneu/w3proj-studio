# Explorer

Extension `w3.explorer`. File tree of the open project.

## Data
Reads the project's folder listing; creates, renames, deletes and opens project files and folders. Writes no map data by itself.

## Contributes
- Commands (5): w3.explorer.refresh, w3.explorer.newFolder, w3.explorer.newFile, w3.explorer.collapseAll, w3.explorer.focus
- Views (1): w3.explorer.files

Full list: `extension.json` in this folder.
